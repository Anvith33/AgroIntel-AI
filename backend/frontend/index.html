    How Our System Works

    📡 Live Data Ingestion

    When you request a prediction, our system pings the OpenWeatherMap API for exact local weather, and the data.gov.in Agmarknet API for the live, state-level Mandi price.

    🧠 Historical Fusion

    We anchor our ML models to the live price, using historical trend patterns (including Black Swan events like the COVID-19 lockdown) to project the future trajectory accurately.

    🌊 Coastal Intelligence

    Our system automatically detects coastal districts and adjusts recommendations for crops like Coconut, Cashew, Banana, Black Pepper, and Tapioca — which thrive near the Indian coastline.
